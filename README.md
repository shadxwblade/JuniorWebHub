# Junior Web Hub

Junior Web Hub - мой небольшой учебный проект, который я делаю в рамках подготовки к соревнованиям JuniorSkills по компетенции «Веб-технологии»

Идея проекта - создать небольшой сайт, в котором можно посмотреть информацию о различных кибератаках и вредоносных программах

## Что уже есть?
- Главная страница с карточками
- Каталог с информацией об объектах
- Поиск по названию
- Раздел с опросом
- Страница с информацией о проекте

## Используемые технологии
- HTML - структура сайта
- CSS - внешний вид и оформление
- JavaScript - функциональность и интерактивность
